# 🚀 GitHub Achievements Guide (2026)

[cite_start]This guide provides simple instructions on how to unlock various badges on your GitHub profile[cite: 1]. 

> [cite_start]**Disclaimer:** This content is intended solely for educational purposes and to show how profile features can be manipulated[cite: 1]. [cite_start]It is not an endorsement to gain unfair advantages over others[cite: 1].

---

## 1. Quick Draw Achievement
* [cite_start]**Step 1:** Create a new public repository or use an existing one[cite: 1, 2].
* [cite_start]**Step 2:** Go to the **Issues** section and open a new issue[cite: 2].
* [cite_start]**Step 3:** Close the issue within **5 minutes** of creating it[cite: 2].

## 2. Pull Request Achievement
* [cite_start]**Step 1:** Edit any file (like the `README.md`) in your repository[cite: 3].
* [cite_start]**Step 2:** Commit the changes and select the option to **create a separate branch and a pull request (PR)**[cite: 3].
* [cite_start]**Step 3:** Merge the pull request into the main branch[cite: 3].
* [cite_start]**Step 4:** Repeat this process a second time to trigger the achievement[cite: 4].

## 3. Reviewer Achievement
* [cite_start]**Step 1:** Add a collaborator (friend or alternate account) in your repository **Settings** under **Access**[cite: 5].
* [cite_start]**Step 2:** The collaborator must accept the invitation from their inbox[cite: 6, 7].
* [cite_start]**Step 3:** Edit a file and create a new pull request[cite: 6].
* [cite_start]**Step 4:** On the PR page, click the settings icon next to **Reviewers** and select the collaborator[cite: 6, 7].
* [cite_start]**Step 5:** Merge the pull request[cite: 7].

## 4. Co-Author Achievement
* [cite_start]**Step 1:** Download and install **GitHub Desktop**[cite: 7].
* [cite_start]**Step 2:** Clone your repository to your local computer[cite: 8].
* [cite_start]**Step 3:** Make changes to a file locally and save it[cite: 8].
* [cite_start]**Step 4:** Create a new branch for these changes in GitHub Desktop[cite: 8, 9].
* [cite_start]**Step 5:** In the bottom-left of the window, use the option to **add a collaborator** to your commit[cite: 9].
* [cite_start]**Step 6:** Push the branch, create a pull request on GitHub, and merge it[cite: 9, 10].
